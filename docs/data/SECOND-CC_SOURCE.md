The full native archive is SECOND-CC-AUG.zip, 2,539,187,782 bytes. Publisher MD5: ca930ddb819d68a797938b940d1711f1.

The connector's transfer relay requires files below 100 MB, so this folder contains 26 ordered byte parts and SECOND-CC-AUG.zip.parts.json. They represent the complete original archive, not a sample. The TerraWatch storage adapter reads them as one seekable ZIP and validates the publisher checksum, without reconstruction or extraction. Native image/semantic/caption member paths are unchanged.

SECOND-CC is a captioned derivative of SECOND. The original SECOND folder is a different source identity. Exclude author augmented copies when selecting original records; group duplicate/reversed pairs before training/test comparisons.
