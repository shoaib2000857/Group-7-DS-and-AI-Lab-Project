# Data pipeline

## Modules

| Module | Responsibility |
|---|---|
| `src/data/catalog.py` | Dataset configuration, mounted/local root selection and JSON/JSONL output |
| `src/data/storage.py` | Safe relative reads from immutable directories, ZIPs and checked split ZIPs |
| `src/data/adapters.py` | Native pair discovery and dataset-specific categorical/binary/semantic decoding |
| `src/data/audit.py` | Decoding, integrity, hashes, source coverage, image/target/text EDA and instruction-parent joins |
| `src/data/preprocess.py` | Exclusion policy, partition protection, target transforms and task-specific manifests |
| `src/data/dataset.py` | Verified image/target batches, answer-isolated instruction inputs, source balancing and paired transforms |
| `src/data/plots.py` | Charts from executed profiles |
| `src/data/acquire.py` | Verified public-release acquisition into local or mounted raw storage |
| `src/data/cli.py` | `audit`, `prepare`, `verify` commands |
| `scripts/build_data_notebooks.py` | Rebuild notebook sources without hand-editing notebook JSON |
| `scripts/run_data_notebooks.py` | Execute all three notebooks, save outputs and record execution checks |

## Record and target contract

One record identifies one ordered pair by dataset/split/filename. Source-relative image/target members are read through a storage root; the local source path is recorded for that execution. Recompute manifests after moving raw storage to another machine or mount. File hashes detect changed inputs. Expected author revisions are distinct from folder snapshots that have not been verified against an author archive.

Native targets retain their meaning:

- MCI grayscale values 0/128/255 become background/road/building indices 0/1/2. Replicated RGB grayscale channels must agree before reduction.
- LEVIR-CD(+), SYSU and WHU binary masks accept declared binary encodings only. Foreground meanings are recorded per source.
- S2Looking's inspected label1 is blue foreground and label2 red foreground. Their union is binary building change. Source label names are preserved; the pipeline does not guess an unverified direction-to-class assignment.
- SECOND uses explicit semantic palettes (unchanged, water, ground, low vegetation, trees, buildings, sports fields). Both temporal class maps and binary change are retained. Building projection is separate.

All original inputs remain unchanged. Prepared targets use nearest-neighbour resizing and class-index PNGs. The loader applies the declared full-frame bilinear RGB resize and [0,1] detector scaling; uint8 images remain available to VLM processors. Original and prepared dimensions and scale factors are recorded. Counts/areas inferred from connected components are not ground-truth instance counts or physical measurements.

## Exclusions and splits

Quality findings and source files are retained; invalid or incompatible joint supervision is quarantined in an explicit ledger. Repeated unordered pairs are grouped, inconsistent targets are quarantined, and redundant records use test > validation > training priority. Cross-split exact frame/tile matches include related datasets. Conservative perceptual candidates are recorded separately from confirmed identity.

Unknown parent-scene IDs remain null. Exact hashing does not prove independence under arbitrary geographic overlap, resampling or illumination changes. Official partitions are preserved; the code never fills absent training partitions from evaluation data.

The final manifests, not arbitrary files left in a target cache, define the prepared population. Regeneration may reuse a cache; do not estimate counts by globbing cached PNGs.

## Supervision separation

Source-record audit files contain references for analysis. Prepared inference records exclude masks, captions, source change flags and target paths. `PairDataset(..., include_targets=False, include_references=False)` returns image data and pair ID only.

`InstructionDataset(..., include_targets=False)` returns the first human prompt and images, without assistant answers. Training mode exposes source conversations explicitly and marks assistant roles as supervision. The selected checkpoint's chat template/tokenizer must generate token-level labels; the data pipeline does not pretend different tokenizers have interchangeable limits.

The new independent human claim audit is not generated by these scripts. Source captions, constructed fixtures and automatic reference checks are not substituted for human factuality judgements.

## Source availability and rights

The catalogue includes all shortlisted sources/aliases and records sources that cannot be executed locally. Missing/empty Drive folders, unresolved shortcuts and geographic-query-dependent context data remain visible. A missing source does not receive fabricated statistics or a zero-valued class distribution.

Use source-specific terms. SECOND-CC and ChangeChat specify CC BY 4.0 for their releases/annotations; underlying imagery terms remain separate. The inspected WHU caption mirror lacks established derivative terms and is excluded from training. HLS needs an explicit area/date/product selection and is not used as individual-building supervision. Large raw datasets are excluded from Git.
