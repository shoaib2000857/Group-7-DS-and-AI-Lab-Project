# Preprocessing experiments

Optional resize-sensitivity, synthetic brightness and paired-transform checks are kept here, separate from the main submission notebooks and reusable pipeline. Saved outputs come from the real-image run documented in `notebook_validation.json`; they are preprocessing checks, not model benchmarks.

Run the main `notebooks/01_EDA.ipynb` and `02_Preprocessing.ipynb` first. Then open `03_Data_Quality_Experiments.ipynb` and run all cells from this repository. Regenerate the notebook source with `python POC/data_quality/build_notebook.py`.
