# Milestone 3 report package

The report source is `Milestone3_Report.md`; the matching eight-page PDF is `output/pdf/TerraWatch_Milestone3_Report.pdf`. It follows the approved report cover/theme and the supplied M3 architecture/model-selection guidance.

- `assets/`: editable vector diagrams, Markdown PNGs and original-theme cover/logo.
- `build_m3_report.py`: reproducible ReportLab builder.
- `qa/layout_checks.json`: page count, bounds and artifact hashes. Rendered review pages and intermediate builds remain local and preserved.
- `CHANGELOG.md`: separate report revision record.
- `TEAM_NOTES.md`: implementation/evidence interpretation for the team.
- `../pipeline/`: corresponding inference/model-worker/training scripts and configuration.
- `../consolidation/`: complete branch/evidence inventory, original-variant archives and check results.

Build from the repository root with `python POC/milestone3/build_m3_report.py`. Run `python POC/consolidation/scripts/run_checks.py` in the CPU validation environment for contract tests (install `POC/evidence/requirements.txt` alongside `requirements-data.txt`). The original GPU screens remain source evidence; no new GPU model result is generated by rebuilding the report.
