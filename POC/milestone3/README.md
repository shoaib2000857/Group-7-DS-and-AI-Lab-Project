# Milestone 3 report package

The report source is `Milestone3_Report.md`; the matching nine-page PDF is `output/pdf/TerraWatch_Milestone3_Report.pdf`. It follows the approved report cover/theme and the supplied M3 architecture/model-selection guidance.

The local implementation and metric comparison for **Sarthak Saini's part** is recorded separately in [sarthak/Benchmark_Report.md](sarthak/Benchmark_Report.md). The report includes the released-RSCaMa and control parity checks, the locally rerun 20%-budget retrain (whose precision differs from the original aggregate), detector/control and visual-witness runs, and a hash-backed [evaluation proof](sarthak/evaluation_proof.json) with static figures. Raw run records, checkpoints and downloaded weights remain ignored local artifacts.

- `assets/`: editable vector diagrams, Markdown PNGs and original-theme cover/logo.
- `build_m3_report.py`: reproducible ReportLab builder.
- `qa/layout_checks.json`: page count, bounds and artifact hashes. Rendered review pages and intermediate builds remain local and preserved.
- `CHANGELOG.md`: separate report revision record.
- `TEAM_NOTES.md`: implementation/evidence interpretation for the team.
- `../pipeline/`: corresponding inference/model-worker/training scripts and configuration.
- `../consolidation/`: complete branch/evidence inventory, original-variant archives and check results.
- `sarthak/`: owner-labelled local benchmark evidence and rerun scripts.
