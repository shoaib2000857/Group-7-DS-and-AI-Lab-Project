# Milestone 3 guidance supplied by the team

By the end of M3 the team demonstrates appropriate model selection, justified choices and a complete end-to-end pipeline design. Applicable report areas:

1. **Introduction:** project recap, M3 objectives and the architecture's relationship to project goals.
2. **System architecture:** diagram, major modules/interactions, data flow, external services/APIs and technology stack.
3. **End-to-end workflow:** user input to final output, module inputs/outputs, flow/sequence diagram, errors/fallbacks, storage/retrieval and user interaction.
4. **Model selection:** models per module, pretrained/custom status, architecture diagrams, size/complexity, formats and integration.
5. **Justification:** alternatives, advantages/disadvantages, compute, expected performance and dataset/task suitability.
6. **Inputs/outputs:** input features, predictions, representations, tokenisation/embeddings and modality-specific preprocessing.
7. **Training:** fine-tuning/feature extraction, transfer learning, frozen/trainable layers, loss, optimiser, learning-rate policy, batch size, epochs, early stopping and checkpoints.
8. **Model pipeline:** preprocessing, feature engineering, intermediate outputs, post-processing and final prediction generation.
9. **Retrieval/knowledge, if applicable:** retrieval, embeddings, vector database, similarity search, chunking and RAG.

Source: TA M. Nagarajan's guidance quoted by Shoaib in this session. Report sections 1-8 cover the applicable image-change architecture; storage/retrieval applicability is addressed in section 2.
